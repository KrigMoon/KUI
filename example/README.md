# Krig's UI Kit Example (KUI Kit Example)

Демо-приложение для пакета [KUI Kit](../README.md) — витрина всех компонентов
и живая песочница для проверки тем.

## Запуск

```bash
cd example
flutter pub get
flutter run
```

Если `example` лежит отдельно от пакета, в `pubspec.yaml` примера укажи путь:

```yaml
dependencies:
  kui:
    path: ../kui
```

## Описание

Приложение — это один `KUIScreen` с плавающим `KUIMenu`, в котором две страницы
и два действия.

**Страницы:**

- **AtomsPage** — витрина компонентов, разложенная по сворачиваемым блокам
  (`KUICollapsibleContainer`): глифы всех стилей и вариантов, карточки, кнопки
  во всех состояниях (включая disabled), вкладки, поля ввода, уведомления и
  «представления» — открытие экрана, диалога и алерта прямо из витрины.
- **PrimePage** — пример реального интерфейса: карточки с текстом и кнопкой,
  плюс форма обратной связи на `KUIInput` + `KUIButton`.

**Действия в меню:**

- 🖌 `brush` — переключает тему по кругу (6 схем: light/dark × amber/ocean/ruby).
  Все компоненты читают `KDColors` через `context.watch`, так что перерисовка
  происходит автоматически.
- ⚪ `circle` — переключает позицию меню (`top`, `bottom`, `left`, `right`).
  Видно, как `KUIMenu` подстраивает раскладку под выбранную сторону.

